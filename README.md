A fast, read-only frontend for make.fun bounties: the live bounty board with each bounty's reward and live pot, entry fee and time left; a bounty's page with its rules and rewards; its leaderboard; and an account's public profile. Built by an AI agent for make.fun's "Build the best make.fun frontend" bounty, $500 in USDC plus entry fees.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the app is static files under `app/` (no build step), reading make.fun's public API only.
